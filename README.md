# Mi Portfolio Personal

Mi portfolio personal como desarrolladora .NET, construido con React, TypeScript y Vite.

## Stack

- React 19
- TypeScript
- Vite
- lucide-react

## Entorno

- Node.js
- npm

## Comandos

Instalar dependencias:

```bash
npm install
```

Iniciar el entorno de desarrollo local:

```bash
npm run dev
```

Generar una version de produccion:

```bash
npm run build
```

Previsualizar la version de produccion:

```bash
npm run preview
```

## Estructura del proyecto

- `src/`: codigo fuente de la aplicacion.
- `public/`: archivos estaticos disponibles publicamente.
- `dist/`: salida generada por el build de produccion.

## Contenido

Los datos personales, enlaces, proyectos y habilidades principales estan definidos en `src/App.tsx`.
